# 05 — Безпека

## 1. Command Injection — захист

**Загроза:** URL передається в `subprocess` → якщо через `shell=True`, можна виконати довільні команди.

**Захист — два рівні:**

**Рівень 1: Whitelist валідація URL (Pydantic + Zod)**
```python
# backend/app/models/job.py — перший бар'єр
pattern = r"^https://(www\.)?(youtube\.com/watch\?v=[\w-]{11}|youtu\.be/[\w-]{11})"
```

```ts
// frontend/src/lib/schemas.ts — клієнтська валідація (UX)
/^https:\/\/(www\.)?(youtube\.com\/watch\?v=[\w-]{11}|youtu\.be\/[\w-]{11})/
```

**Рівень 2: Defense in depth у `downloader.py`**
```python
def _safe_url(url: str) -> str:
    """Re-validate before passing to yt-dlp."""
    if not YOUTUBE_URL_RE.match(url):
        raise ValueError("Invalid YouTube URL")
    return url
```

**Рівень 3: `shell=False` скрізь (ОБОВ'ЯЗКОВО)**
```python
# Правильно ✅
subprocess.run(["yt-dlp", "--no-playlist", safe_url], shell=False)

# ЗАБОРОНЕНО ❌
subprocess.run(f"yt-dlp {url}", shell=True)
```

При `shell=False` аргументи передаються як список — shell не інтерпретує спецсимволи.

## 2. Prompt Injection — захист

**Загроза:** Відео може навмисно містити текст типу "Ignore all previous instructions..." у субтитрах → маніпуляція Gemini.

**Захист у `ai_analyzer.py`:**
```python
MAX_TRANSCRIPT_CHARS = 8000

def _sanitize_transcript(transcript: str) -> str:
    # 1. Truncate
    transcript = transcript[:MAX_TRANSCRIPT_CHARS]

    # 2. Remove injection patterns
    injection_patterns = [
        r"ignore (all |previous |above )?instructions?",
        r"you are now",
        r"new instructions?:",
        r"system prompt",
        r"forget everything",
    ]
    for pattern in injection_patterns:
        transcript = re.sub(pattern, "[REMOVED]", transcript, flags=re.IGNORECASE)

    return transcript
```

## 3. Path Traversal — захист

**Загроза:** `GET /api/jobs/../../../etc/passwd/download` — вихід за межі директорії.

**Захист у `api/jobs.py`:**

```python
# 1. Валідація UUID формату job_id
try:
    uuid.UUID(job_id)
except ValueError:
    raise HTTPException(400, "Invalid job ID")

# 2. Resolve і перевірка межі директорії
storage = Path(settings.local_storage_path).resolve()
short_path = (storage / job_id / "short.mp4").resolve()

if not str(short_path).startswith(str(storage)):
    raise HTTPException(400, "Invalid path")
```

## 4. Resource Exhaustion — захист

**Загроза:** Завантаження 10-годинного відео → OOM / переповнення диску.

**Захист:**
```python
# Ліміт тривалості (downloader.py)
MAX_DURATION_SECONDS = 30 * 60  # 30 хв
if info["duration"] > MAX_DURATION_SECONDS:
    raise ValueError(...)

# Ліміт розміру файлу (yt-dlp flag)
"--max-filesize", "2G"

# Timeout subprocess (5 хв на завантаження, 2 хв на FFmpeg)
subprocess.run(..., timeout=300)
subprocess.run(..., timeout=120)
```

## 5. Rate Limiting

**Загроза:** Один користувач може запустити сотні задач, виснаживши сервер.

**Захист:**
```python
# 5 відео на IP на день
RATE_LIMIT_PER_DAY = 5

# Redis counter з TTL 24 год
def get_user_job_count(ip: str) -> int:
    return int(_redis.get(f"ratelimit:{ip}") or 0)

def increment_user_job_count(ip: str) -> None:
    pipe = _redis.pipeline()
    pipe.incr(f"ratelimit:{ip}")
    pipe.expire(f"ratelimit:{ip}", 86400)
    pipe.execute()
```

IP береться через `X-Forwarded-For` для роботи за reverse proxy (Nginx/Caddy).

## 6. API ключі та секрети

**Правила:**
- Всі ключі — виключно через `.env` / environment variables
- `.env` у `.gitignore` (обов'язково!)
- `.env.example` без реальних значень — можна комміттити
- Ніколи не логувати API ключі

**Змінні, що містять секрети:**
```
GEMINI_API_KEY    # Google Gemini
SECRET_KEY        # підпис токенів (генерувати: openssl rand -hex 32)
```

**Перевірка перед деплоєм:**
```bash
git grep -i "api_key\|secret\|password" -- "*.py" "*.ts"
# Має повернути тільки читання з os.environ / Settings
```

## 8. Автоочистка тимчасових файлів

**Загроза:** Без очистки `/tmp/repurposer_jobs` переповниться за лічені дні.

**Захист — Celery beat кожні 6 год:**
```python
@celery_app.task
def cleanup_old_jobs():
    now = time.time()
    for job_dir in storage.iterdir():
        if now - job_dir.stat().st_mtime > FILE_TTL_SECONDS:
            shutil.rmtree(job_dir, ignore_errors=True)
```

## Чекліст безпеки перед деплоєм

- [ ] `.env` не потрапив у git (`git status` чистий)
- [ ] `SECRET_KEY` згенеровано (`openssl rand -hex 32`)
- [ ] `CORS_ORIGINS` вказує на реальний домен, не `*`
- [ ] `shell=False` у всіх `subprocess.run` викликах
- [ ] Redis не відкритий назовні (тільки internal Docker network)
- [ ] `/tmp/repurposer_jobs` є тільки у Docker volume, не публічний
- [ ] Celery beat запущений (автоочистка працює)
