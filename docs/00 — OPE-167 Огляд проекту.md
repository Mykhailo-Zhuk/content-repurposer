# OPE-167 — Meme / Content Repurposer

Сервіс автоматичної нарізки YouTube відео на Shorts/Reels за допомогою AI. Знаходить найцікавіші моменти у відео → генерує короткий вертикальний кліп + заголовок + опис + теги для публікації в соцмережах.

## Мета

Автоматизувати процес:
1. Отримання YouTube відео за посиланням
2. AI-аналіз transcript: пошук найбільш engaging моментів
3. Рендер вертикального short (9:16, 1080×1920) через FFmpeg
4. Генерація метаданих: заголовок, опис, теги
5. Надання готового файлу для завантаження

## Архітектура

```
[Користувач] → [Next.js Frontend]
                      │
                      ▼ POST /api/jobs/
               [FastAPI Backend]
                      │
                      ▼
               [Celery Worker]
                    │   │   │
                    ▼   ▼   ▼
              [yt-dlp] [Gemini] [FFmpeg]
                    │         │
                    ▼         ▼
              [Transcript] [short.mp4]
                    │
                    ▼
               [Redis (job state)]
                      │
                      ▼ GET /api/jobs/{id}
               [Frontend polling]
                      │
                      ▼
              [Завантаження результату]
```

## Pipeline обробки відео

| Крок | Відповідальний | Що відбувається |
|---|---|---|
| 1. Валідація URL | FastAPI (Pydantic) | Whitelist regex перед будь-якою обробкою |
| 2. Rate limit | FastAPI + Redis | Max 5 відео на IP на день |
| 3. Постановка в чергу | Celery | Job ID → Redis, статус = `queued` |
| 4. Завантаження | yt-dlp | Відео .mp4 + auto-subtitles .vtt |
| 5. Парсинг субтитрів | downloader.py | VTT → plain text, дедупліація |
| 6. AI аналіз | Gemini | Transcript → момент + title + description + tags |
| 7. Рендер | FFmpeg | Вирізає кліп → scale 1080×1920 → short.mp4 |
| 8. Збереження | job_store.py | Результат у Redis, файл у /tmp/repurposer_jobs |
| 9. Видача | FastAPI | FileResponse на /api/jobs/{id}/download |
| 10. Автоочистка | Celery beat | TTL 24 год, кожні 6 годин |

## Acceptance Criteria (MVP)

- [ ] Користувач вставляє YouTube посилання → отримує готовий short за ≤ 5 хв
- [ ] Відображається прогрес: черга → завантаження → AI аналіз → рендер → готово
- [ ] При помилці — зрозуміле повідомлення українською мовою
- [ ] Ліміт: max 30 хв відео, max 2 GB файл
- [ ] Rate limit: 5 відео на IP на день
- [ ] Вихідний формат: .mp4, 1080×1920, 9:16 (Shorts/Reels/TikTok)
- [ ] Разом з відео — заголовок, опис, теги для копіювання
