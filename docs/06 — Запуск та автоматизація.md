# 06 — Запуск та автоматизація

## Швидкий старт

### Вимоги

- Docker Engine 24+
- Docker Compose v2
- Git

### Локальний запуск (Docker)

```bash
# 1. Клонувати репо
git clone https://github.com/{org}/content-repurposer.git
cd content-repurposer

# 2. Налаштувати змінні оточення
cp .env.example .env
# відкрити .env і вписати GEMINI_API_KEY

# 3. Запустити всі сервіси
docker compose up --build

# Або у фоні:
docker compose up --build -d
```

Після запуску доступно:
| URL | Сервіс |
|---|---|
| http://localhost:3000 | Frontend |
| http://localhost:8000 | Backend API |
| http://localhost:8000/docs | Swagger UI |

### Локальний запуск без Docker

**Backend:**
```bash
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Потрібен локальний Redis
redis-server &

# API сервер
uvicorn app.main:app --reload --port 8000

# Celery worker (окремий термінал)
celery -A app.workers.celery_app worker --loglevel=info

# Celery beat (окремий термінал)
celery -A app.workers.celery_app beat --loglevel=info
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## Docker Compose сервіси

| Сервіс | Образ | Порт | Призначення |
|---|---|---|---|
| `frontend` | ./frontend | 3000 | Next.js |
| `backend` | ./backend | 8000 | FastAPI |
| `worker` | ./backend | — | Celery worker |
| `beat` | ./backend | — | Celery beat (cron) |
| `redis` | redis:7-alpine | 6379 | Черга + state |

`worker` і `beat` використовують той самий Docker образ що й `backend`, але різну команду запуску (`CMD`).

## Deploy на VPS

### Вимоги до сервера

- Ubuntu 22.04+
- Docker + Docker Compose
- 2+ CPU, 4+ GB RAM (FFmpeg вимогливий)
- 20+ GB disk (для тимчасових відео)

### Деплой

```bash
# На сервері
git clone https://github.com/{org}/content-repurposer.git /opt/content-repurposer
cd /opt/content-repurposer

cp .env.example .env
# Заповнити .env

docker compose -f docker-compose.yml up -d --build
```

### Nginx (reverse proxy)

```nginx
server {
    listen 80;
    server_name repurposer.yourdomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /api/ {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        # Великі відповіді (video download)
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

### CORS для продакшену

Оновити `.env`:
```
CORS_ORIGINS=https://repurposer.yourdomain.com
NEXT_PUBLIC_API_URL=https://repurposer.yourdomain.com
```

## Автоочистка (Celery beat)

Beat автоматично запущений як окремий Docker сервіс.

```python
# Розклад (celery_app.py)
"cleanup-old-jobs": {
    "schedule": crontab(hour="*/6"),  # кожні 6 годин
}
```

Видаляє директорії старші за `FILE_TTL_SECONDS` (24 год).

Перевірити що beat працює:
```bash
docker compose logs beat | grep "cleanup"
```

## Чекліст перед запуском

- [ ] `.env` заповнено (`GEMINI_API_KEY` є)
- [ ] `SECRET_KEY` згенеровано
- [ ] `CORS_ORIGINS` відповідає домену фронту
- [ ] Docker має доступ до інтернету (для yt-dlp)
- [ ] Є достатньо місця на диску (мін. 10 GB free)
- [ ] Celery worker і beat запущені (`docker compose ps`)
- [ ] Redis здоровий (`docker compose exec redis redis-cli ping` → PONG)
